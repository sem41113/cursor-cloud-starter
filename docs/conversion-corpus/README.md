## 三种信息，不要混用

### 报告原文要求

来源：《微信综合打印小程序 V1.0｜架构审查与技术方案》B.1、B.2、E.6、F.1 第9项、F.4。

- F.1 第9项：能否提供 30 到 50 份脱敏的真实文档，以及店内 Word 或 WPS 打印出来的对照结果。这是转换方案验证的前提。
- B.1：在这 30 到 50 份真实样本上比较页数一致率和人工目检通过率。报告建议页数一致率达到或超过 95% 时默认自建，否则默认云端，并写明该阈值需要产品负责人确认。
- B.1 同时要求：默认转换器放在无外网容器中的 LibreOffice，限制耗时和内存，每次使用独立配置目录；解析 DOCX 字体表，缺字体时提示核对版式。
- B.2：预览和打印都从同一份规范化 PDF 派生。规范化包括修复、去掉权限密码、拒绝需要打开密码的文件、拍平表单和批注、记录每页尺寸和旋转、计算 SHA-256。打开密码的拒绝单独作为异常用例，不进入这 30 到 50 份的一致率分母；按设计拒绝记为该异常用例通过。
- E.6：转换回归比较样本语料的页数和页面像素；升级 LibreOffice 或字体后必须重跑。开发环境模拟不能替代真实打印验收。
- F.4：Phase 0 才执行转换样本对比。本目录是这项执行之前的准备，不是 Phase 0 的测试结果。

### 已获产品负责人确认的决策

以下决策覆盖报告里「低于 95% 则把云转换设为默认」的旧建议。不得因为那条旧建议自动把云转换设为默认。

- 默认使用自建转换。
- 第三方云转换只作备用。
- 使用备用转换前，用户必须明确选择，并完成适当授权。
- 后台可以关闭备用转换，并可以设置预算。
- 费用由商家承担。
- 试运行暂定上限：¥0.05/页、¥5/文件、¥10/日、¥100/月。
- 启用前必须核验服务商正式报价。

### 仍待确认的建议门槛

- 报告建议的 95% 页数一致率。它只作为待确认门槛，本次准备不把它写成通过或失败标准。
- 人工目检通过率的数值门槛。报告要求记录这个比率，没有给出数值。
- 重大版式问题的定义和允许比例。
- 页面像素差异用来分拣目检，还是直接判定通过。报告只要求比较像素，没有给出百分比。
- 各类样本的最低份数、长文档页数、对照采用「打印到 PDF」还是必须实物扫描。这些是本准备为了让收集可执行而拟定的规则，产品负责人可以改。
- 自建转换的具体超时时间和内存上限。报告只要求限制，没有给数值。
- 备用云服务商是哪一家。报告把 WPS 开放平台和腾讯云数据万象列为备选，没有选定。
- OnlyOffice 是否纳入本次对照。报告建议纳入样本对照，产品负责人尚未确认。
- 试运行预算上限在看到正式报价之后是否维持。

### 本准备的执行选择

这些选择用来把 F.1 第9项做成 Word 转换对照，不是报告原文。

- 30 到 50 份限定为 DOC 或 DOCX，并且 R 样本必须能直接打开。
- 店内对照本次采用打印到 PDF。是否接受，仍在待确认事项里。
- 两个 SHA-256 只核对接交之后源文件和对照件没有改变。对照 PDF 确实由该源文件打印，靠店内生成和登记流程。
