# 真实样本收集清单

报告 F.1 第9项的原文是：30 到 50 份脱敏的真实文档，以及店内 Word 或 WPS 打印出来的对照结果。B.1 要求在这些真实样本上比较页数一致率和人工目检通过率。原文没有规定扩展名，也没有规定对照必须是 PDF。

本清单为这次 Word 转换对照做了两项执行选择：

1. 纳入这 30 到 50 份的文件限定为 DOC 或 DOCX。
2. 店内对照采用 Word 或 WPS 打印到 PDF，并登记打印设置。这种方式是否接受，仍待产品负责人确认。

本清单把这个范围排成可执行名额：核心 35 份 + 压力样本 5 份，合计 40 份。R-41 到 R-50 是可选加项，总数不超过 50。某一类为 0 份时，即使总数已经达到 30，覆盖仍然不足。缺类需要产品负责人书面豁免后，才能进入正式汇总。这个分类配额同样是执行选择，可以调整。

合成文档不得占用 R 编号。需要打开密码、用来验证「按设计拒绝」的文件使用 X 编号。二者都不计入这 30 到 50 份，也不进入转换一致率分母。

## 收集人先读

1. 按 [02-脱敏与版本对应规则.md](02-脱敏与版本对应规则.md) 操作。顺序是：隔离原件、脱敏、保存、立刻用这个脱敏文件打印对照、填写清单。
2. 每份样本复制一份 [templates/单份样本环境与对照表.md](templates/单份样本环境与对照表.md)，编号与下表相同。
3. 样本放在仓库以外。不要把真实文件提交到 Git，不要上传到第三方转换服务。
4. 下表「收集状态」只允许填写：未收集、已封存、已退回。不要填写测试结论。

## 预期拒绝（不计入 30 到 50 份）

报告 B.2 要求拒绝需要打开密码的文件。这个行为单独测试，不放进转换一致率。

| 编号 | 要覆盖的情况 | 收集状态 | 记录 |
|---|---|---|---|
| X-01 | 脱敏后的 DOC/DOCX，由店内设置测试用打开密码 | 未收集 | 预期拒绝记录 |
| X-02 | 可选的第二份，格式与 X-01 不同（一份 DOC、一份 DOCX） | 未收集 | 预期拒绝记录 |

X 样本的规则：

- 先脱敏，再由店内设置测试口令。不保留客户原来的口令，也不把口令写进样本包以外的聊天或仓库。口令只记在店内离线的预期拒绝记录里。
- 不制作店内打印对照，不比较页数、目检和像素。
- 不占用 R 编号。同一份文件不能既是 R 又是 X。
- 转换器拒绝打开：该异常用例记为通过。
- 转换器仍然产出 PDF，或把文件当成可转换：该异常用例记为不通过。
- 这两种结果都不记入转换失败，都不计为重大版式问题，都不进入页数一致率和人工目检通过率。

客户原件若有打开密码，又希望它参加页数对照：在店内合法解除密码，再按 R 样本脱敏和打印。解除不了，就不要收入 R 样本。

只限制编辑或打印、但打开时不需要密码的文件，仍然可以做 R 样本。规范化时按 B.2 去掉这类权限密码。不要把它们编成 X。

## 每份 R 样本必须同时具备的三件东西

缺任何一件，收集状态保持「未收集」或改为「已退回」，不能改为「已封存」。

### 1. 脱敏后的源文件

- 扩展名是 `.doc` 或 `.docx`。
- 这一份文件就是将来自建转换的唯一输入。
- 文件名使用编号，例如 `R-07-source.docx`。不要保留客户原文件名。

### 2. 店内打印对照

对照必须由上面的那一份源文件，在店内电脑上用 Word 或 WPS 打印产生。F.1 原文只要求店内打印对照；下面的 PDF 形式是本准备的执行选择，尚未确认。

- 使用「Microsoft Print to PDF」或 WPS 的打印到 PDF。
- 纸张按该文档实际设置，缩放为实际大小 100%。
- 环境表记录软件名称、完整版本号、操作系统、虚拟打印机或物理打印机名称、是否打印批注、是否打印修订、是否打印背景色。
- 得到 `R-07-reference.pdf`。
- 建议另外拍摄或扫描首页、一张含表格或图片的页面、末页。照片放在该样本的 `photos/` 目录，只供人工查看。照片不参与页数统计。

不能充当对照的文件：

- LibreOffice 或其他转换器导出的 PDF。
- 脱敏之前打印的 PDF。
- 只有手机照片、没有打印 PDF。
- 由另一台电脑或另一个软件版本重新打开后另存，再打印的文件。

### 3. 环境与版本表

使用 [templates/单份样本环境与对照表.md](templates/单份样本环境与对照表.md)。至少包括：

- 样本编号、版本号、脱敏人和封存时间。
- 源文件 SHA-256、对照 PDF SHA-256。这两个摘要用来核对接交之后文件没有被改动。它们不能单独证明对照 PDF 是由该源文件打印的，仍要靠下面的店内生成登记。
- 店内软件是 Word 还是 WPS，以及完整版本号。
- 操作系统版本。
- 打印设置：纸张、缩放、批注、修订、背景。
- 该文档实际使用的字体。DOCX 可从字体表读取；DOC 读不全时要注明。
- 店内电脑是否安装：宋体、仿宋_GB2312、方正小标宋、黑体、微软雅黑、Times New Roman、Calibri。
- 主类别和附带特征，对应本清单的哪一行。

## 封存前的当场核对

- [ ] 已在环境表登记：对照是在哪一台店内电脑、用哪个 Word 或 WPS 版本、在哪一次保存之后立即打印的。
- [ ] 两份文件都已计算 SHA-256，并写进环境表。摘要只封存当前字节，不代替上一条登记。
- [ ] 环境表里的页数是对照 PDF 的页数，不是估计值。
- [ ] 全文检索过样本中不应再出现的手机号、证件号和真实单位名称。
- [ ] 样本包里没有「真名—占位」对照表。
- [ ] R 样本没有打开密码，封存文件可以直接打开。客户原件有打开密码时，先在店内合法解除，再脱敏并打印对照。解除不了就不要编入 R。要测试拒绝行为时，另做 X 样本。
