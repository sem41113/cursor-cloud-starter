# 真实样本收集清单

样本量来自报告 F.1 第9项和 B.1：30 到 50 份脱敏真实 DOC/DOCX，每份都要有店内 Word 或 WPS 的打印对照。

本清单把这个范围排成可执行名额：核心 35 份 + 压力样本 5 份，合计 40 份。R-41 到 R-50 是可选加项，总数不超过 50。某一类为 0 份时，即使总数已经达到 30，覆盖仍然不足。缺类需要产品负责人书面豁免后，才能进入正式汇总。这个分类配额是本准备拟定的执行规则，可以调整。

合成文档不得占用 R 编号，也不得计入这 30 到 50 份。

## 收集人先读

1. 按 [02-脱敏与版本对应规则.md](02-脱敏与版本对应规则.md) 操作。顺序是：隔离原件、脱敏、保存、立刻用这个脱敏文件打印对照、填写清单。
2. 每份样本复制一份 [templates/单份样本环境与对照表.md](templates/单份样本环境与对照表.md)，编号与下表相同。
3. 样本放在仓库以外。不要把真实文件提交到 Git，不要上传到第三方转换服务。
4. 下表「收集状态」只允许填写：未收集、已封存、已退回。不要填写测试结论。

## 每份样本必须同时具备的三件东西

缺任何一件，收集状态保持「未收集」或改为「已退回」，不能改为「已封存」。

### 1. 脱敏后的源文件

- 扩展名是 `.doc` 或 `.docx`。
- 这一份文件就是将来自建转换的唯一输入。
- 文件名使用编号，例如 `R-07-source.docx`。不要保留客户原文件名。

### 2. 店内打印对照

对照必须由上面的那一份源文件，在店内电脑上用 Word 或 WPS 打印产生。

- 使用「Microsoft Print to PDF」或 WPS 的打印到 PDF。
- 纸张按该文档实际设置，缩放为实际大小 100%。
- 环境表记录软件名称、完整版本号、操作系统、虚拟打印机或物理打印机名称、是否打印批注、是否打印修订、是否打印背景色。
- 得到 `R-07-reference.pdf`。
- 建议另外拍摄或扫描首页、一张含表格或图片的页面、末页。照片放在该样本的 `photos/` 目录，只供人工查看。照片不参与页数统计。

不能充当对照的文件：

- LibreOffice 或其他转换器导出的 PDF。
- 脱敏之前打印的 PDF。
- 只有手机照片、没有打印 PDF。
- 由另一台电脑或另一个软件版本重新打开后另存，再打印的文件。

### 3. 环境与版本表

使用 [templates/单份样本环境与对照表.md](templates/单份样本环境与对照表.md)。至少包括：

- 样本编号、版本号、脱敏人和封存时间。
- 源文件 SHA-256、对照 PDF SHA-256。
- 店内软件是 Word 还是 WPS，以及完整版本号。
- 操作系统版本。
- 打印设置：纸张、缩放、批注、修订、背景。
- 该文档实际使用的字体。DOCX 可从字体表读取；DOC 读不全时要注明。
- 店内电脑是否安装：宋体、仿宋_GB2312、方正小标宋、黑体、微软雅黑、Times New Roman、Calibri。
- 主类别和附带特征，对应本清单的哪一行。

## 封存前的当场核对

- [ ] 源文件和对照 PDF 来自同一次保存。中间没有再次编辑。
- [ ] 两份文件都已计算 SHA-256，并写进环境表。
- [ ] 环境表里的页数是对照 PDF 的页数，不是估计值。
- [ ] 全文检索过样本中不应再出现的手机号、证件号和真实单位名称。
- [ ] 样本包里没有「真名—占位」对照表。
- [ ] 文件没有设置打开密码。若客户原件有打开密码，先在店内用合法授权解除，再脱敏；解除不了就不要收入本次语料。环境表注明原件曾有密码，但封存的源文件本身必须能直接打开。
