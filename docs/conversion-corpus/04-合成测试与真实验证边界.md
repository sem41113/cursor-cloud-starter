# 合成测试与真实验证的边界

当前没有真实样本。本轮也没有生成合成样本，没有安装或调用 LibreOffice，没有调用云转换。

合成样本使用 S 编号。真实样本使用 R 编号。两套编号不得对调，不得在汇总时相加。

## 现在可以做的合成测试

这些工作不依赖客户文件，也不依赖店内打印。它们只检查工具和记录表能不能用。做完之后，F.1 第9项仍然未关闭。

| 编号建议 | 可以构造的内容 | 能够验证的事 | 不能验证的事 |
|---|---|---|---|
| S-01 到 S-06 | 用脚本生成的普通中文、中英混排、标题和列表 | 转换命令、临时目录、超时、哈希和页数读取 | 与店内 Word/WPS 是否一致 |
| S-07 到 S-12 | 指定宋体、黑体、Calibri 的短文。环境没有该字体时故意记录缺字体 | 字体表解析和缺字体记录 | 公文字体在店内电脑上的真实分页 |
| S-13 到 S-18 | 合并单元格、嵌套表、跨页表 | 记录模板中的 TABLE 归因栏 | 店内软件的表格排版 |
| S-19 到 S-23 | 文本框和环绕图 | FLOAT 记录栏 | 店内环绕结果 |
| S-24 到 S-27 | 页眉、奇偶页、分节 | HEADER 记录栏 | 店内页眉 |
| S-28 到 S-31 | 纵向页中插入横向页 | ORIENT 记录栏 | 店内打印驱动是否旋转 |
| S-32 到 S-35 | 程序生成的 30 页以上文档 | 长文档的耗时、内存和页数读取 | 真实长文档的重排 |
| S-36 | 带批注的文档 | 拍平前后页数是否变化 | 店员打印时是否勾选了批注 |
| S-38 | 另存为 DOC | DOC 分支能否跑通 | 客户旧版 DOC 的兼容性 |
| S-39 | 含页码域和目录域 | FIELD 记录栏 | 客户保存时域有没有更新 |

合成测试的对照如果需要，只能标成「合成侧自备对照」，并且写明它是由哪一个软件导出的。它不是店内打印对照。没有店内对照时，合成结果的「页数一致率」栏留空，不写 0，也不写 100%。

合成测试允许现在开始。开始时单独建立运行编号，前缀使用 `CONV-SYN-`。结果只写入合成运行记录，不写入 [templates/汇总记录.md](templates/汇总记录.md) 的真实样本栏。

## 必须等待真实样本和店内对照的验证

下面每一项都要等 R 编号样本通过接收检查。

- 报告 F.1 第9项要求的 30 到 50 份真实文档是否收齐。
- 每一份是否有同一脱敏版本的店内 Word 或 WPS 打印对照。
- 真实样本的页数一致率。
- 真实样本的人工目检通过率。
- 真实样本的重大版式问题份数和主因分布。
- 公文字体、复杂表格、浮动对象、页眉页脚、混合方向、长文档在店内排版下的实际差异。
- 缺字体提示是否对应店内电脑真正安装过的字体。
- 批注和修订在店内所选打印设置下，拍平之后是否与对照一致。
- 升级 LibreOffice 或字体之后的真实语料回归。报告 E.6 的这项要求依赖这套真实语料。
- 任何关于自建转换是否达到待确认门槛的判断。
- 关闭 F.1 第9项。

收到第一批样本后，仍然先做接收检查。接收检查通过之前，不用这些文件做试点转换。试点转换如果以后需要，使用单独的 `CONV-PILOT-` 编号，不写入正式汇总。
